# Fuel Mode

Fuel Mode is a local-first recipe generator for athletes. It offers curated Random recipes and pantry-driven recipes, with training goals, dietary preferences, meal types, and cuisine inspiration.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deployment

This project is a static site. On Vercel, use the **Other** framework preset, leave the build command empty, and use the repository root as the output directory.
